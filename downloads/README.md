# KiCad installer

[Download EMI-Assistant-0.2.1.zip](EMI-Assistant-0.2.1.zip?raw=true)

Install this ZIP using **KiCad → Plugin and Content Manager → Install from File**. Keep the ZIP intact. Version 0.2.1 adds the license notices and viewer to the tested 0.2.0 simulation release. GitHub’s source-code ZIP is for developers.

The checksum is in [SHA256SUMS.txt](SHA256SUMS.txt). New builds produced by the Actions workflow are available as workflow artifacts and have their own checksums printed during the build.
